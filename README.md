# JJUK Visual Studio 官網原始碼

這是依照「檔案系統驅動」邏輯建立的 GitHub 官網架構。

## 目錄說明
- `studio`: 存放關於工作室的內容（團隊、理念）。
- `works`: **核心作品集**。請依照 `yymmdd_專案名` 建立子資料夾。
- `solutions`: 存放專業服務方案與報價說明。
- `journal`: 工作日誌與深度文章。
- `policy`: 法律與隱私權規範。
- `.github/workflows`: 存放自動化掃描腳本（待開發）。

## 如何新增作品？
1. 在 `works` 建立新資料夾，例如 `260314_RHCL泡澡球`。
2. 放入 `cover.jpg` 作為封面。
3. 放入作品圖檔（建議按 01, 02... 命名）。
4. 上傳至 GitHub，網站會自動偵測並更新。
